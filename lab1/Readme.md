1. Для одного типа самолета может быть несколько схем салона.  
2. Каждое место относится к одной конкретной версии схемы салона.  
3. Место \- уникально в каждое схеме  
4. При изменении компоновки создается новая версия схемы. Старая версия сохраняется.  
5. Для каждого самолета хранится история использования схем салона.  
6. В расписании указываются маршрут, дни выполнения, плановые времена и период действия.  
7. По расписанию создаются рейсы на конкретные даты.  
8. У каждого рейса есть аэропорт вылета и аэропорт прибытия.  
9. На рейс назначается конкретный самолет. При замене самолета сохраняются данные о предыдущем назначении.  
10. Самолет нельзя назначить на рейс, если на это время у него запланировано техническое обслуживание либо же его текущий статус не допускает эксплуатацию.  
11. Одно бронирование может включать нескольких пассажиров и несколько сегментов перелета.  
12. Для каждого пассажира на каждый сегмент перелета оформляется отдельный билет.  
13. Одно место на рейсе нельзя одновременно закрепить за несколькими действующими билетами.  
14. При замене самолета на самолет с другой схемой сохраняются старые назначения места, результаты их переназначения.  
15. Для перелетов с пересадкой сохраняется связь между сегментами и проверяется минимальное время пересадки.  
16. Сотрудника можно назначить на рейс только при наличии действующего допуска к типу самолета и выполняемой роли.  
17. В назначении сотрудника указываются рейс, роль и период назначения.  
18. Сотрудник не может одновременно участвовать в несовместимых по времени рейсах.  
19. Техническая работа относится к конкретному самолету. Для нее указываются вид работы, период, исполнитель и результат.  
20. Руководитель получает отчеты по пунктуальности, загрузке рейсов, заменам самолетов, работе экипажей и техническим простоям.  
21. При отмене или обмене билета исходная запись сохраняется
